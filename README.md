# Retail Sales Exploratory Data Analysis

## Objective

The objective of this project is to perform Exploratory Data Analysis (EDA) on retail sales data to identify customer behaviour, sales trends, product performance, and actionable business insights.

## Dataset

The dataset contains 1000 retail transactions with 9 columns:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed

- Data inspection
- Data type analysis
- Missing value analysis
- Date conversion
- Descriptive statistics
- Gender distribution
- Age group distribution
- Revenue by product category
- Monthly sales analysis
- Quarterly sales analysis
- Correlation analysis
- Customer age vs total spending

## Key Findings

- Electronics generated the highest revenue.
- The 46–55 age group had the highest number of transactions.
- Sales varied across different months and quarters.
- Average spending was nearly the same for male and female customers.
- There was no obvious relationship between customer age and total transaction amount.

## Project Files

- `Retail_Sales_EDA.ipynb` — Complete EDA analysis
- `retail_sales_dataset.csv` — Dataset used for analysis

## Conclusion

The analysis provides insights into customer demographics, product performance, and sales trends. These findings can help businesses improve product planning, customer targeting, and promotional strategies.
